# Pomodoro Timer

A clean, accessible Pomodoro Timer web application built with vanilla HTML, CSS, and JavaScript. No frameworks, no dependencies.

## Project URL
https://roadmap.sh/projects/pomodoro-timer

## Live Demo
Deployed via GitHub Pages — open `index.html` directly in any browser.

## Features
- Start, pause, and resume the timer
- Three session types: Work, Short Break, Long Break with color coding
- Auto-advances to the next session when timer ends
- Configurable intervals via the Settings panel
- Tracks work sessions and completed cycles
- Progress bar showing time remaining visually
- Bell sound via Web Audio API when a session ends
- Page title updates with current timer so you can monitor from other tabs
- Keyboard shortcuts: Space to start/pause, R to reset
- Fully responsive on desktop and mobile
- Accessible with ARIA labels and keyboard navigation

## Default Configuration
| Session | Duration |
|---------|----------|
| Work | 25 minutes |
| Short Break | 5 minutes |
| Long Break | 15 minutes |
| Sessions before Long Break | 4 |

## How to run
Open `index.html` in any browser — no build step or server required.

## Tech
- HTML5
- CSS3
- Vanilla JavaScript
- Web Audio API (for bell sound)
